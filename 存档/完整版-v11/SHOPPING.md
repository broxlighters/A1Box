# A1BOX 采购清单

依据 `HARDWARE.md` v3，以及原作者在模型说明里列的配件。

- 关键词可直接在淘宝、拼多多里搜。
- 带 ⚠ 的项，下单前要先和卖家确认。

## 第 1 批：控制板（2026-11-12 已下单）

- [x] **鹿小斑问天 ESP32C3-PRO（带屏版）** ×1：已在好好搭搭官方品牌店下单，排针已焊
  - 关键词：`鹿小班 ESP32C3-PRO`
  - ⚠ 选带板载小屏的那款，不要选 MINI。
  - ⚠ 有「焊接排针」选项就选**焊好排针**的。排针朝下、屏幕朝上，插到洞洞板的排母上，坏了能直接拔下来换。
  - 顺便问卖家要原理图，主要想知道板载小屏接在哪几个引脚上。
- [x] **Guition JC3248W535** ×1：已在创客英雄下单，型号 JC3248W535C（电容触摸、带外壳）
  - 关键词：`JC3248W535`
  - 已拿到接口图和尺寸图，放在 `硬件资料/JC3248W535/`。
  - ⚠ 还缺**各接口的引脚定义或原理图**，要靠它确认串口和 5V 接在哪个接口上，请再找卖家要一下。
  - 这款自带外壳，外形 94.5×62mm，我们只需设计一个固定支架。
  - **配件：1.25mm 4Pin IO 线 ×2，一起买。** 屏幕的扩展口是 1.25mm 间距的小插座，普通杜邦线插不上。这根线一头是 1.25mm 插头，另一头是杜邦头，用来接主控的串口和 5V 供电。线不够长可以剪断再接长。
  - 配件：外接喇叭，**暂时不买**。提示音功能以后再考虑，到时候单买就行。
- [x] **Seeed XIAO ESP32S3 Sense** ×1：已在 seeedstudio 企业店铺下单，OV5640
  - 关键词：`XIAO ESP32S3 Sense`
  - 实际发货的是 OV5640 自动对焦款，宣传图上的 OV3660 是旧款。
  - ⚠ 确认附带摄像头扩展板和外接天线；选不焊排针的；选 Seeed（矽递）官方或授权店。
- [ ] **Type-C 数据线** ×1（家里有就不用买）：用来给板子烧录。
  - 三块板共用一根，只在第一次烧录时用到，以后都通过 WiFi 升级。
  - 要能传数据，只能充电的线不行。
  - 电脑那一头是 USB-A 还是 USB-C，按你电脑的接口来选。

## 树莓派（HA 主机，用现有的 3B+）

- [ ] **TF 卡** 32GB 以上，标有 A2 的高耐久款。HA 一直在写数据库，普通卡容易坏。
- [ ] **树莓派 3B+ 电源**：5V 2.5A，Micro USB 口。手机充电器供电不稳，容易出问题。
- [ ] **网线**：安装时必须插网线，平时也建议用有线连接。

## 第 2 批：箱体材料（原作者清单）

- [ ] **透明亚克力板**：找亚克力店按尺寸切割。成品外部尺寸是 宽 480 × 长 590 × 高 580mm。

  | 位置 | 厚度 | 尺寸（mm） | 数量 |
  |---|---|---|---|
  | 左、右侧板 | 3mm | 503 × 513 | 2 |
  | 底板 | 3mm | 403 × 513 | 1 |
  | 后板 | 3mm | 403 × 207 | 1 |
  | 门 | 3mm | 185 × 490 | 2 |
  | 顶板 | **5mm** | 403 × 513 | 1 |

- [ ] **螺丝**：M2.5×8 ×100、M2.5×16 ×50、M4×30 ×4
  - 新增的打印件要用的螺丝，等设计时再定。大概率是 M2.5 或 M3，可以顺手买一盒 M2.5/M3 螺丝套装。
- [ ] **钕磁铁** 4×1.5mm ×50：关键词 `钕铁硼 强磁 圆片 4x1.5`
- [ ] **静音海绵**：约 3cm 厚，垫在打印机下面，这是原作者要求的。按箱底大小剪，约 40×50cm。
- [ ] **PETG 耗材**：建议买 **5kg**（5 卷）
  - 按原作者参数切片（0.2mm 层高、2 层墙、10% 填充），27 盘共用约 **4.1kg**，A1 上总打印时间约 **170 小时**。
  - 多出来的约 0.9kg，留给打失败重打和新设计的零件。
  - 颜色按原文件的分配：主色约 2.6kg，第二色约 1.1kg，点缀色约 0.3kg。另有约 8g 是灯罩，要用**透明或半透明** PETG。颜色可以按自己喜好换。
- [ ] **滤芯**：用原设计同款，滤网罩是按它的尺寸设计的。
  - 关键词：`飞利浦 车载净化器 滤芯 ACA308`（兼容 CP100/180/200，H13 HEPA + 活性炭）

## 第 2 批：电子件

### 电源

- [ ] **24V 10A 电源适配器**（240W）×1
  - 关键词：`24V10A 电源适配器`
  - 选有 3C 认证的品牌款。
- [ ] **XT60 插头**：面板安装公头 ×1，带线母头 ×1
  - 关键词：`XT60 面板座`、`XT60 母头 带线`
  - 母头接适配器一侧。
- [ ] **5×20mm 面板安装保险丝座** ×1，**10A 慢断保险丝** 1 盒（留备用）
  - 关键词：`5x20 保险丝座 面板`、`5x20 慢断 10A`
- [ ] **船型开关** 16A ×1
  - 关键词：`船型开关 16A`
  - ⚠ 选**不带灯**的。带灯款大多是 220V 氖灯，接 24V 不会亮。
- [ ] **降压模块** 24V→5V 3A ×1，建议多买 1 个备用
  - 关键词：`LM2596 降压模块` 或 `XL4015 降压模块`
  - ⚠ 输入上限要 ≥ 36V。**不要买 MP2307**，它的输入上限只有 23V。
- [ ] **接线端子** 若干：用来分配 24V、5V、GND
- [ ] **XT30 插头** 公母 2 对：加热器线在上下两半分界处用
  - 关键词：`XT30 公母 带线`
  - 关键词：`WAGO 221 接线端子`，2 位、3 位、5 位各几个。

### 灯光与排风

- [ ] **排风扇**：24V 12025 四线 PWM，高静压款 ×1
  - 关键词：`12025 24V 四线 PWM 风扇`
  - ⚠ 要卖家给规格书，确认电压是 24V、四根线、线序怎么接。
- [ ] **24V COB 灯带** 约 1m，白光
  - 关键词：`24V COB 灯带 8mm`
  - ⚠ 宽度 ≤ 8mm，原设计的灯罩截面约 12×12mm。剪切单位越短越好，因为要剪成 4 段，每段约 164mm。

### 开关驱动

- [ ] **MOSFET 驱动模块** ×2，多买 1 个备用
  - 关键词：`D4184 MOS管 触发开关 驱动模块`
  - ⚠ 商品页要写明**支持 3.3V 触发**，标称电流 ≥ 10A。
- [ ] **继电器模块**：1 路，5V 线圈 ×1
  - 关键词：`5V 继电器模块 1路 光耦隔离 高低电平触发`
  - ⚠ 要写明**支持 3.3V 触发**，触点 ≥ 10A 30VDC。
- [ ] **S8050 三极管**：买一小包
- [ ] **电阻套装**：1/4W 金属膜，要包含 1k 和 10k
- [ ] **洞洞板** 5×7cm：买 2–3 块，留一块练手
- [ ] **2.54mm 单排排母** 1×40 ×2：焊在洞洞板上，主控插上去，以后好拆换
  - 主控两侧各 11 针，要剪成两条 11 针。排母剪的时候会损失一针，所以买 40 针的长条剪。

### 传感器与按键

- [ ] **SHT40 温湿度模块** ×1
  - 关键词：`SHT40 温湿度传感器模块 I2C`
- [ ] **轻触开关** 12×12×5mm，四脚：买一包
  - ⚠ 尺寸要和原作者用的一样，原设计的按键帽才装得上。

### 安全器件

- [ ] **KSD301 温控开关**：常闭，60°C，10A ×2（1 个备用）
  - 关键词：`KSD301 常闭 60度 10A`
  - 选带固定耳的款式，方便用螺丝固定在框架上。

### 线材与辅料

- [ ] **18AWG 硅胶线**：红、黑各 3m，用于 24V 主线和加热器
- [ ] **22AWG 硅胶线**：红、黑各 5m，用于灯带、风扇、5V 供电
- [ ] **24AWG 多股线**：多色，约 15m，用于信号线
- [ ] **XH2.54 端子线**：公母对插、带线的，2P、3P、4P 各几对
- [ ] **热缩管套装**

### 工具（没有的话要买）

- [ ] **万用表**：必需。降压模块要先用它调到 5.1V，再接板子。
- [ ] 电烙铁、焊锡、剥线钳
- [ ] 热风枪或打火机：用来收热缩管

## 第 3 批：箱子装好、实测温度后再买

- [ ] **PTC 加热器**：24V，自带风扇，功率待定（暂定 100W）
  - 先不开加热打一次 PA，实测箱温能到多少，再决定买多大功率。
- [ ] **温度保险丝** 10A ×2：动作温度要等加热器装好、实测附近温度后再选
- [ ] **加热器的金属支架和隔热垫**：等支架设计好再定
