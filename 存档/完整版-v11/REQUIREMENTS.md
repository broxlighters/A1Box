# A1BOX 需求说明

版本：**v11 定稿**（2026-11-12）。之后的改动都写进文末的「变更记录」。

标注了「默认」的数值是提议，可以改；标注了「待定」的见第 8 节。

## 1. 目标

给开放式拓竹 A1 做一个封闭箱，箱体基于 MakerWorld 模型「A1封箱pro」（`Al封箱pro.3mf`）。

- 主要打印 PETG，偶尔打印 PA
- 功能：照明、排风过滤、恒温加热、温湿度监测、视频监控、触摸屏和实体按键控制
- 通过 Home Assistant 用手机控制，并和打印机自动联动。第一版只在局域网内使用，见第 6 节

## 2. 系统组成

| 部件 | 作用 |
|---|---|
| 主控：鹿小斑问天 ESP32C3-PRO（带板载小屏的版本） | 控制灯、风扇、加热器，读取传感器，执行全部安全逻辑 |
| 触摸屏：Guition JC3248W535（ESP32-S3，3.5 寸 320×480 电容触摸屏） | 本地操作界面，和主控用线直连 |
| 摄像头：Seeed XIAO ESP32S3 Sense（OV5640 自动对焦款） | 视频监控、截图，装在箱体框架里 |
| 树莓派 3B+（Home Assistant OS 64 位） | 手机控制、和打印机联动、推送通知 |
| 拓竹 A1 + ha-bambulab 插件 | 提供打印状态、当前耗材类型、层数等信息 |

箱子上保留原设计的两个实体按键（见 4.8），和触摸屏同时可用。

## 3. 供电

- 外置 24V 10A（240W）电源适配器。220V 交流电不进箱子，也不从打印机取电。
- 电源接口用 XT60 或 GX16 航空插头，额定电流 10A 以上。
- 24V 输入端加保险丝和总电源开关。总开关是最后一道手动断电手段。
- 24V 直接供电给加热器、排风扇、灯带。
- 24V 降压到 5V，给三块 ESP32 板供电。
  - 降压模块的标称输入要在 36V 以上，输出 3A。
  - 不用原设计的 MP2307，它的输入上限是 23V。

## 4. 功能需求

### 4.1 照明

- 24V COB 灯带，装在原设计的 4 个灯条位置。
- PWM 调光，亮度 0–100%。
- 可以在触摸屏、按键 1 和 HA 上控制。
- 开始打印时自动开灯。
- 打印后排风结束时自动关灯。
- 上电时灯是关的。

### 4.2 排风与过滤

- 24V 12025 四线 PWM 风扇，装在原设计的风扇罩位置，配 H13 HEPA + 活性炭滤芯。
- 风要穿过滤芯，所以选静压较高的型号。
- PWM 调速，转速 0–100%。
- **必须能完全停转**：很多四线风扇在 0% PWM 时仍保持最低转速，PWM 线悬空时还会全速转。所以要加一个风扇电源开关（高边开关，直接切断风扇的 24V），由主控单独控制。
  - 上电时默认断开，风扇不转。
  - PA 模式和「关闭」模式下断开，保证不漏热。
- 监测转速：风扇通电、转速设定 ≥ 30%，但实测转速明显过低、持续 30 秒，就报警。风扇断电时不检查。
- 什么时候排风、排多快，由模式决定（见 4.5）。

### 4.3 加热

- 24V 自带风扇的恒温 PTC 加热器。功率暂定 100W（约 4.2A），待定。
- 只在 PA 模式下工作。
- 目标温度可调范围 30–45°C，默认 42°C，最高不超过 45°C。
- PTC 自带的风扇和发热体同时通电，这一点在接线上保证，不靠软件。
- 加热器不能直接接触 PETG 打印件，要用金属支架或隔热安装。支架需要新设计。
- **安装位置**：放在下半部分靠后的角落，贴近箱底，热风横着吹，让热空气自然往上走。
  - 具体位置要等 A1 放进箱子后再定，不能挡住热床前后移动。
  - 不放在上半部分。热空气本来就往上聚，加热器再放上面会上热下冷；而且离电子仓和摄像头太近。
  - 原作者说「下半部分不放电子件」，指的是控制电路。加热器只是被控制的负载，可以放下半部分。
- **走线**：加热器的线沿原作者穿 AMS 线的通道向上走，即 4 号模块的圆孔经 B 立柱，进入上半部分的电子仓。
  - 上下两半没有用螺丝固定，可以分开，所以加热器的线在分界处加一个能插拔的 XT30 接头。
- KSD301 装在上半部分框架上，那里是箱内最热的位置；温度保险丝装在加热器支架上。
- 开关器件用 MOSFET 模块，额定电流不低于工作电流的 2 倍。具体型号见 `HARDWARE.md`。

### 4.4 传感器

- **温湿度**：SHT40，装在箱体中上部，远离热床和加热器出风口。
- **不检测门的开关**：开门只会让箱温下降，不会造成危险，各项安全保护也都不依赖门的状态。

### 4.5 模式

| 模式 | 加热 | 排风 |
|---|---|---|
| 关闭 | 关 | 关 |
| PETG | 关 | 按箱温自动调速，把箱温压在上限以下 |
| PA | 恒温到目标温度 | 关 |
| 打印后排风 | 关 | 全速运行 10 分钟（默认），结束后回到「关闭」 |

- PETG 模式的箱温上限：可调范围 25–38°C，默认 33°C。
- PETG 模式的排风速度：箱温低于「上限 − 5°C」时不排风；从这里开始随温度升高而加快，到上限时全速。
- PA 模式可以在打印前手动开启，用来预热。
- 灯光不受模式影响，单独控制。

### 4.6 和打印机联动（全自动，由 HA 执行）

- **开始打印**：开灯，并按当前耗材类型选择模式。
  - PA 类耗材（PA、PA-CF、PAHT 等）：进入 PA 模式。
  - 其他耗材，或者识别不出类型：进入 PETG 模式，不加热。
- **打印完成、失败或取消**：进入「打印后排风」，排风结束后关灯。
- **打印暂停**：保持当前模式不变。
- **手动优先**：在屏幕、按键或 HA 上手动改过模式后，这一次打印不再自动改模式。
- **只在事件发生时动作**：联动只在打印开始、结束这类时刻动作一次，不会反复改回去。比如打印中手动关了灯，它不会再自己打开。
- **离线时**：HA 或打印机离线时联动停止，本地功能和安全保护不受影响。
- **接入方式**：ha-bambulab 用云模式接入，不开开发者模式，Bambu Handy 照常可用。
- **已知限制**：打印机不会等箱子预热好再开始打印，所以打 PA 时要提前手动预热。

### 4.7 触摸屏

**硬件与连接**

- Guition JC3248W535，3.5 寸 320×480 电容触摸屏，自带外壳。
  - 外形 94.5×62mm，显示区 73.4×49mm，厚度等实物到了再量。
  - 装在箱体前方，具体位置待定。屏幕自带外壳，所以只需新设计一个固定支架，大概率利用外壳背面四角的螺丝孔固定，以实物为准。
  - 接口都在背面下沿，右侧有 Type-C。支架要给 Type-C 留开口，以后 WiFi 升级失败时还能插线重新烧录。
  - 板子带电池接口，本项目不用电池。
- 屏幕板装在箱壁外侧，避免长期处在 45°C 里。
- 和主控用串口线直连。
  - 不依赖路由器和 HA，断网时屏幕照样能控制箱子。
  - ESPHome 的 `packet_transport` 组件支持这种连接方式。

**显示内容**

- 箱温、湿度，以及最近 1 小时的温度曲线
- 当前模式、加热状态、目标温度、排风速度
- 故障和报警信息
- 打印进度、剩余时间、当前耗材。这些数据来自 HA，HA 离线时不显示。
- WiFi 和 HA 的连接状态

**可以做的操作**

- 开关灯、调亮度
- 切换模式
- 调整 PA 目标温度和 PETG 箱温上限
- 手动排风
- 清除故障

**息屏与唤醒**

- 一段时间无人操作后自动变暗，然后息屏。
- 触摸屏幕即可唤醒。
- 出现故障时自动亮屏并显示故障信息。

### 4.8 实体按键

- 两个 12×12 自复位轻触按键，装在原设计的按键位置，按键帽用原设计的 P22。不用自锁按键。
- **按键 1**：按一下开灯，再按一下关灯。
- **按键 2**：一键全关。停止加热和排风，模式回到「关闭」。灯由按键 1 单独控制，不受影响。
- 按键直接接在主控上，不经过屏幕板，屏幕坏了也能用。
- 和屏幕、HA 同时可用，互不冲突：
  - 按键只发指令（切换灯、全关），状态只记在主控上，执行后同步到屏幕和 HA。
  - 多处同时操作时，主控按先后顺序处理，最后一次操作生效。
  - 按键操作算手动操作，适用「手动优先」规则（见 4.6）。

### 4.9 视频

- Seeed XIAO ESP32S3 Sense，带 OV5640 自动对焦摄像头（500 万像素，最高 2592×1944）和 8MB PSRAM。
  - 商品宣传图上是 OV3660，但实际发货的是 OV5640，因为 Seeed 正在换代。
- **视角**：OV5640 的视角比广角镜头窄。设计安装件之前，先实测摄像头在框架上的哪个位置、什么角度能拍全打印平台，安装件做成角度可调。
- 装在箱体上半部分的框架里，镜头朝向打印平台。具体位置在设计安装件时定，要保证能拍到整个打印平台。
- 5V 电从上半部分的降压模块引过来。
- **防过热**：PA 模式下箱温会到 45°C，而 XIAO 的工作温度上限是 65°C。
  - 安装件做成「镜头朝里、板子背面通向箱外」：板子所在的小腔体开口朝向箱外，和箱内空气隔开，用室温空气散热；只留一个小窗口让镜头看进箱内。
  - 如果框架结构做不到开口朝外，至少给摄像头和芯片加散热片。
  - 远离加热器出风口。
  - 没人看画面时，自动降到每 10 秒 1 帧，减少发热。
  - 监测 S3 芯片温度，超过 75°C 时报警并降低帧率。这个芯片温度读数在 80°C 以上不准，所以阈值不能再高；具体数值待实测后调整。
- **对焦**：ESPHome 不支持 OV5640 的自动对焦，上电后镜头停在默认位置，拍 20–40cm 外的打印平台可能会偏虚。
  - 先实测画面清不清楚。
  - 不清楚的话，写一个小的自定义组件，开机时触发一次对焦。乐鑫的摄像头驱动有对焦接口。
- **散热片**：OV5640 发热比 OV3660 大。如果附带散热片，一定要装上。
- **天线**：XIAO 必须接外接天线，套装里自带。
  - 天线贴在安装件朝箱外的一侧，远离加热器支架这类金属件。
  - 天线座（U.FL）很脆，插拔次数有限。线要固定住，不要反复拔插。
- 可以在 HA App 和浏览器里看实时画面，第一版限家里局域网。
- 打印完成或出故障时，拍一张截图推送到手机。

### 4.10 手机推送（HA App）

第一版不做外网访问：
- 文字通知在外面也能收到。iPhone 没有问题；安卓手机要看有没有谷歌服务。
- 通知里的截图要回到家里 WiFi 才能加载出来。

- 打印完成，附截图
- 箱体故障，附故障原因和截图
- 排风扇停转
- 摄像头芯片过热
- 主控掉线

## 5. 安全需求

### 5.1 硬件保护（不依赖固件）

- 加热器主回路串一个 KSD301 温控开关（常闭，60°C 断开）。
  - 装在箱内上部框架上，感受箱内空气温度，避开加热器出风口。
  - 放在主回路而不是控制回路：MOSFET 最常见的坏法是击穿后一直导通，只有切断主回路才能让加热器停下来。
  - KSD301 冷却后会自动恢复接通。
- 加热器主回路再串一个温度保险丝。它是一次性的，熔断后要更换，用来防 KSD301 触点粘死。
- PTC 发热体本身有自限温特性，算是额外一层保护，但设计上不依赖它。
- 24V 输入端装保险丝和总电源开关。

### 5.2 软件保护（在主控上本地执行）

| 触发条件 | 处理 |
|---|---|
| 箱温超过 50°C | 进入故障状态：停止加热，全速排风，锁定；必须手动清除后才能再次加热 |
| 加热器连续工作 60 分钟仍未到达目标温度 | 进入故障状态，提示「请检查门是否关好、加热器是否正常」 |
| 温度传感器 30 秒没有新数据 | 停止加热；如果当时在 PA 模式，进入故障状态 |
| 上电 | 不加热，模式回到「关闭」 |

- WiFi、HA 或屏幕断开，都不影响上述保护。
- 屏幕坏了或连接线断了：主控照常运行，仍然可以用实体按键开关灯和一键全关，也可以用 HA App 控制，或者直接关总电源。

## 6. 网络与集成

- 三块 ESP32 板都接入 Home Assistant，通信加密。
- 支持通过 WiFi 升级固件（OTA），升级过程加密。
- 暂不接入米家。
- **HA 主机**：用现有的树莓派 3B+（1GB 内存），装 Home Assistant OS 64 位版。
  - 3B+ 的配置低于 HA 官方建议的 2GB 内存，第一版的负载够用。
  - 固件在电脑上编译，不在树莓派上编译。
  - 以后要做延时摄影、AI 识别，或者 HA 不再支持 3B+ 时，换树莓派 4/5（4GB）或迷你主机，用 HA 的备份还原迁移过去。
- **第一版只做局域网**：
  - 手机要连着家里 WiFi，才能看画面、控制箱子、加载推送里的截图。
  - 外网访问以后再做，可选方案有 Tailscale、公网 IPv6 加动态域名、Nabu Casa。

## 7. 以后可以加的功能

第一版不做，先记下来。

**摄像头相关（2026-11-12 记录）**

- **A. 首层检查截图**
  - 第一层打完后拍一张推送到手机，用来尽早发现首层没贴好。
  - 层数由 ha-bambulab 提供。
- **B. 看画面时自动开灯**
  - 摄像头板开始推流时，通知 HA 开灯；看完延时关灯。
  - 解决关灯时画面一片黑的问题。
- **C. 延时摄影**
  - 每换一层，树莓派从摄像头拍一张，打印结束后用 ffmpeg 合成视频并推送。照片和视频存在树莓派上。
  - 每层拍摄时打印头的位置不同，合成后画面会跳。要拍得干净，得配合切片软件里的「平滑模式」。
  - A1 自带的摄像头也能拍延时摄影，可以作为备选。
- **D. AI 识别打印失败（炒面）**
  - 定时截图交给 AI 判断，发现炒面就提醒。
  - 树莓派算力不够跑本地模型；用云端 AI 要按次收费，图片也要上传到外网。效果要实测。

**其他**

- **外网访问**：见第 6 节。
- **米家和小爱同学**：经 HA 转接到巴法云。
- **声音提示**：故障报警、打印完成提示等。屏幕板有喇叭接口，ESPHome 支持播放提示音，加一个几块钱的外接喇叭就能做。2026-11-12 决定暂不做。
- **从 HA 控制打印机**：比如等箱子预热好再开始打印。这需要开开发者模式，开了以后 Bambu Handy 无法使用。

2. ~~**触摸屏板**~~ 已定：Guition JC3248W535。
3. ~~**摄像头板**~~ 已定：Seeed XIAO ESP32S3 Sense。
4. **需要新设计的打印件**：
   - 屏幕固定支架（屏幕自带外壳）
   - 加热器支架
   - 摄像头安装件：嵌在上半部分框架里，带通向箱外的散热腔
   - 温湿度传感器、电源接口、总开关的安装位
5. **独立的内循环风扇**：是否需要。加热时 PTC 自带的风扇已经在吹，可能不需要。需要的话用空出来的 GPIO10。
6. ~~**实现方式**：用 ESPHome 还是 Rust。~~ 已定：三块板子全部用 ESPHome。
7. **主控板载小屏的接口**：待拿到实物确认。
   - 如果是 I2C OLED（常见地址 0x3C），就和 SHT40（地址 0x44）共用 GPIO5/6 这条 I2C 总线，没有冲突。
   - 如果它另外占用了别的引脚，第 9 节的引脚表要调整。
   - 这块小屏装在电子仓里，盖上后看不见，默认不使用。
8. **屏幕各接口的引脚定义**：卖家给的接口图只标了接口位置，没写每个脚是什么。要找卖家要引脚定义或原理图，确认串口 TX/RX 和 5V 输入在哪个接口上。
9. **屏幕接上 5V 后会不会自动开机**：板子带电池接口和电池开关按钮，要实测确认。如果需要按键才开机，停电恢复后屏幕就不会自己亮。
10. **摄像头的视角和对焦**：到货后实测能否拍全打印平台、画面清不清楚，再设计安装件，并决定要不要写对焦组件。

## 9. 主控引脚分配（已确认）

两种规格的 ESP32C3-PRO（MINI 和带屏版）都能用这张表，本项目用带屏版。

| GPIO | 接什么 | 说明 |
|---|---|---|
| 0 | 加热器 MOSFET 模块 | 上电时引脚悬空，模块自带下拉，保证上电不加热 |
| 1 | 灯带 MOSFET 模块，PWM 调光 | |
| 2 | 按键 2（一键全关） | 启动配置引脚，上电时必须是高电平，所以外加 10k 上拉电阻到 3.3V |
| 3 | 排风扇 PWM 信号，经 S8050 三极管 | 三极管导通时把信号拉低，固件里要把 PWM 反相 |
| 4 | 排风扇电源开关 | 上电时默认断开 |
| 5 | I2C SDA：SHT40 | 板载小屏可能也在这条总线上 |
| 6 | I2C SCL：SHT40 | |
| 7 | 板载 LED，用作状态指示灯 | 备用引脚 |
| 8 | 排风扇测速 | 启动配置引脚；测速线外加 10k 上拉到 3.3V，上电时风扇没电，线上是高电平 |
| 9 | 按键 1（开关灯） | 启动配置引脚，和板载 BOOT 键是同一个脚。开机时按住会进入烧录模式，重新上电即可恢复 |
| 10 | 空闲（备用） | 去掉门磁后空出来的 |
| 20 | 串口接收 ← 屏幕 TX | |
| 21 | 串口发送 → 屏幕 RX | 上电时芯片会从这个脚发出一段启动日志，屏幕端按数据包开头的校验标记识别后丢弃 |

- GPIO18/19 是 USB 口用的，不能占用。
- 固件日志走 USB 输出，这样串口 0（GPIO20/21）就空出来给屏幕连接用。
