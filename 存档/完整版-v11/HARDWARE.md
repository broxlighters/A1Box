# A1BOX 硬件设计：物料清单与接线

版本：草案 v5（2026-11-12），依据 `REQUIREMENTS.md` v11（定稿）。

- 标「待确认」的地方，见第 5 节。
- 价格以购买时为准，所以本文不列价格。

## 1. 电源分配总览

```
24V 10A 适配器（箱外）
 └─ XT60 面板座
     └─ 10A 慢断保险丝
         └─ 总电源开关（船型开关）
             ├─ 24V 端子排
             │   ├─ 加热器支路：MOSFET 模块 A（GPIO0）→ 温度保险丝 → KSD301 → PTC 加热器（含自带风扇）
             │   ├─ 灯带支路：  MOSFET 模块 B（GPIO1）→ 4 段 24V COB 灯带（并联）
             │   ├─ 排风扇支路：继电器触点（GPIO4）→ 12025 四线风扇（PWM 由 GPIO3 经 S8050 控制）
             │   └─ 降压模块 24V → 5V
             │       └─ 5V 端子排
             │           ├─ 主控 ESP32C3-PRO（5V 脚）
             │           ├─ 触摸屏 JC3248W535
             │           ├─ 摄像头 XIAO ESP32S3 Sense
             │           └─ 继电器模块线圈
             └─ GND 端子排：所有地线共地
```

**电流估算**

| 负载 | 电流（24V 侧） |
|---|---|
| PTC 加热器 100W（待定） | 约 4.2A |
| 排风扇（24V 12025 高静压） | 约 0.3–0.6A |
| 灯带（4 段，共约 0.66m） | 约 0.3A |
| 降压模块（5V 侧约 1.2A） | 约 0.3A |
| **合计** | **约 5.5A**；10A 适配器留有余量 |

### 3.3 加热器（主回路 18AWG，信号线 24AWG）

| 从 | 到 | 说明 |
|---|---|---|
| 24V 端子排、GND 端子排 | 模块 A 的 VIN+、VIN− | |
| 模块 A 的 OUT+ | KSD301（上半部分框架）→ XT30 接头 → 温度保险丝（加热器支架）→ 加热器 + | 两个保护器件串联在加热器正极上 |
| 加热器 − | XT30 接头 → 模块 A 的 OUT− | |
| 主控 GPIO0 | 模块 A 的信号 +（标作 PWM+ 或 TRIG） | |
| 主控 G | 模块 A 的信号 − | |

加热器自带风扇时，把风扇的正负极和发热体的正负极并在一起，接在同一路开关后面。这样只要发热体通电，风扇就一定在转，不依赖软件。

**加热器放在下半部分**，线从电子仓沿原作者的 AMS 线通道往下走：B 立柱 → 4 号模块的圆孔。

上下两半在分界处用 XT30 接头连接，拆箱子时拔开就行。

## 4. 安装和接线注意事项

1. **共地**：所有 GND 都接到同一个 GND 端子排上。主控、各个模块的信号地，必须和 24V 的地连通。
2. **先调电压再接板子**：降压模块先空载调到 5.1V，用万用表确认后，再接三块板。
3. **不要同时接 USB 和箱体电源**：第一次用 USB 给主控烧录时，先断开箱体的 24V。这块板的 USB 5V 和 5V 引脚之间有没有防倒灌的二极管，资料里没写。之后升级固件都走 WiFi，不用再插 USB。
4. **检查开关模块的上电状态**：MOSFET 模块和继电器模块到手后，先单独上电确认：信号脚不接时，输出必须是断开的。
5. **KSD301 的位置**：装在箱内上部框架上，感受的是箱内空气温度。不要放在加热器出风口，否则正常加热时也会误断开。
6. **加热器不碰 PETG 件**：加热器用金属支架固定，和 PETG 打印件之间留空隙或加隔热垫。
7. **电子仓空间**：PRO 板比原设计用的 MINI 长，电子仓里还要多放 2 个 MOSFET 模块、1 个继电器模块和洞洞板。装之前先摆一下，看放不放得下。
